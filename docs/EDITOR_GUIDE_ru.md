# Руководство редактора «Эрта аниқла» (CMS Wagtail)

> Для копирайтеров, врачей-рецензентов и администраторов контента.
> Узбекская версия: [EDITOR_GUIDE_uz.md](EDITOR_GUIDE_uz.md). Скриншоты: `tests/e2e/screenshots/cms-*.png`
> (обновляются автоматически тестом `tests/e2e/test_cms_workflow.py`).

## 1. Главные правила

1. **Сайт не ставит диагноз.** Каждое медицинское утверждение проходит медицинскую проверку
   (раздел 6). Без неё страница не получает отметку «Проверено врачом».
2. **Две языковые версии — узбекская (латиница) и русская.** Каждая страница должна существовать в обеих.
   Узбекская кириллица добавляется отдельной версией (см. раздел 5.3).
3. **Заглушки.** Во всех страницах, созданных при запуске, стоят метки
   `[[TODO: content — copywriter]]` (текст пишет копирайтер) и `[[VERIFY: doctor]]` (факт проверяет врач).
   Перед публикацией в тексте не должно остаться ни одной такой метки.
4. **Персональные данные пациентов** — только с письменного согласия (раздел 8). Никогда не
   публикуйте ФИО, телефоны, фото документов.

## 2. Вход в CMS и двухфакторная аутентификация

Адрес: `https://ertaaniqla.uz/cms/`.

| Шаг | Что делать | Скриншот |
|---|---|---|
| 1 | Введите логин и пароль (минимум 12 символов). После 5 ошибок вход блокируется на 1 час. | `cms-01-login.png` |
| 2 | **Первый вход:** CMS попросит подключить устройство. Установите приложение-аутентификатор (Google Authenticator, Microsoft Authenticator, Яндекс Ключ), отсканируйте QR-код, введите 6-значный код, нажмите «Сохранить». | — |
| 3 | **Каждый вход:** введите текущий 6-значный код из приложения. | `cms-02-2fa-code.png` |

- Потеряли телефон — напишите администратору: он удалит старое устройство, и при следующем входе вы подключите новое.
- Сессия действует 8 часов. На чужом компьютере всегда нажимайте «Выйти».
- Язык интерфейса CMS: аватар внизу слева → *Учётная запись* → *Предпочтения* → *Язык*.
  Узбекский перевод интерфейса Wagtail неполный, поэтому многие редакторы выбирают русский.

## 3. Роли

| Роль (группа) | Кто | Может | Не может |
|---|---|---|---|
| **Editor** (редактор) | копирайтер | создавать и редактировать страницы на всех языках, переводить, отправлять на проверку, загружать изображения, документы, видео, вести глоссарий, учреждения, вопросы | публиковать, удалять, менять настройки сайта и пользователей, видеть обращения «Обратной связи» |
| **Medical Reviewer** (врач-рецензент) | врач РОНЦ / Центра матери и ребёнка / детской онкогематологии | проверять страницы, отправленные на медицинскую проверку, править их во время проверки, **одобрять** (публикация + отметка) или **запрашивать правки**, отвечать на вопросы посетителей, править определения глоссария | создавать страницы, публиковать без проверки |
| **Admin** (администратор контента) | руководитель контента | всё, что редактор, + публикация, удаление, настройки сайта, редиректы, пользователи, процессы проверки, обращения обратной связи | — |

Разработчик (суперпользователь) назначает роли: *Настройки → Пользователи → пользователь → Роли*.
В поле «Организация» пользователя-врача укажите учреждение — оно выводится в отметке «Проверено врачом».

## 5. Создание и перевод страницы

### 5.1 Новая статья (`cms-04-add-article.png`)

1. *Страницы* → нужная тема (например, «Осведомленность») → «⋯» → *Добавить дочернюю страницу* → **Статья**.
2. Вкладка **Содержимое**:
   - **Заголовок** — коротко, простыми словами (≤ 60 символов).
   - **Краткое описание** (обязательно, ≤ 300 символов) — показывается в карточках, меню, поиске.
   - **Главное изображение** — по желанию; у каждого изображения должен быть *альтернативный текст*.
   - **Содержимое** — нажмите ⊕ и выберите блок (таблица блоков ниже).
3. Вкладка **Продвижение**: *Slug* (часть адреса, латиницей: `faktory-riska`), SEO-заголовок,
   описание для поисковиков, изображение для соцсетей (если не выбрано — создаётся автоматически).
4. Кнопка внизу: **Сохранить черновик** — сохраняет без публикации. Стрелка ▲ рядом →
   **Отправить на модерацию** (`cms-05-submit-for-moderation.png`).

### 5.2 Перевод на другой язык (`cms-06-translate-submit.png`, `cms-07-translation-edit-uz.png`)

1. Откройте страницу-оригинал → меню «⋯» вверху → **Перевести эту страницу** (или адрес
   `/cms/localize/submit/page/<id>/`).
2. Отметьте язык (например, *Oʻzbekcha*) → **Отправить**. Родительские страницы создаются автоматически.
3. Откроется обычный редактор копии страницы: замените **все** тексты, заголовок и slug на
   узбекские (`xavf-omillari`), проверьте ссылки.
4. **Отправить на модерацию** — перевод проверяется врачом **отдельно** (отметка у каждой языковой версии своя).

Переключатель языка на сайте ведёт на переведённую страницу; пока перевода нет — на главную раздела.

### 5.3 Узбекская кириллица

Кириллическая версия узбекского текста формируется из латинской версии (см. раздел 12 и
DECISIONS D-047 / M7b). Отдельно переводить на кириллицу не нужно; пишите узбекский текст
**латиницей** с правильными знаками `oʻ gʻ ʼ`.

### 5.4 Блоки содержимого

| Блок | Для чего | Советы |
|---|---|---|
| Текст (rich text) | обычные абзацы, подзаголовки H2/H3, списки, ссылки | не используйте H1 — он уже есть (заголовок) |
| Выделенный блок | «Не откладывайте визит», предупреждения; вид: информация / предупреждение / опасность / хорошая новость / **успокоение** | «успокоение» — для страниц симптомов («этот признак не всегда рак») |
| Три колонки / Две колонки | таблицы ТЗ «Уход и поддержка», «Жизнь после рака», «Для родителей / Для близких» | в каждой колонке заголовок + список |
| Шаги | маршрут пациента (4 шага), самообследование груди | номер можно не указывать — проставится 01, 02…; поле «Срок» — например срок направления по ПП-402 |
| Карточки | 6 видов детского рака, факторы риска | иконка или изображение, заголовок, текст, ссылка |
| Список симптомов | признаки со срочностью: планово / в ближайшее время / срочно | срочность показывается цветом, значком и текстом |
| Статистика | цифры по Узбекистану | обязательно источник и год |
| Видео | ролик из библиотеки видео или ссылка YouTube/Telegram | добавьте подпись и **расшифровку** (доступность + поиск) |
| Галерея изображений | инфографика | включите «можно скачать» для материалов |
| Документ для скачивания | памятки PDF для печати | — |
| Вопросы-ответы (аккордеон) | «Вопросы, которые важно задать врачу» | — |
| Термины глоссария | определения выбранных терминов | термины из глоссария также подсвечиваются в тексте автоматически |
| Список учреждений | «Где пройти» | фильтр по региону / типу / «бесплатно» |
| Призыв к действию (CTA) | кнопка «Найти, где пройти скрининг» | ссылка на страницу сайта предпочтительнее внешней |
| Цитата | слова пациента / врача | только с согласия |
| Таблица | график скрининга | первая строка — заголовки |
| Встраивание | Instagram, TikTok, Telegram, YouTube | Instagram/TikTok загружаются только по нажатию посетителя |

## 6. Медицинская проверка (врач-рецензент)

1. Редактор нажимает **Отправить на модерацию** → страница попадает в процесс **Medical review**.
2. Врач входит в CMS: на главной панели блок **«Ожидает вашей проверки»** (`cms-08-dashboard-reviewer.png`).
3. Врач открывает страницу, при необходимости правит текст, затем внизу стрелка ▲ (`cms-09-approve.png`):
   - **Одобрить как проверенное врачом и опубликовать** — страница публикуется, на ней появляется
     «✓ Проверено врачом: *имя*, *организация* (*дата*)» (`cms-10-live-with-badge.png`);
   - **Одобрить с комментарием** — то же + комментарий редактору;
   - **Запросить правки** — страница возвращается редактору с комментарием, ничего не публикуется.
4. Отметку нельзя поставить вручную: в настройках страницы (вкладка *Настройки → Медицинская
   проверка*) она только отображается. Новая версия страницы проходит проверку заново —
   дата в отметке обновится.
5. Администратор тоже не может одобрить проверку, если он не состоит в группе Medical Reviewer.

Статус процессов: *Отчёты → Процессы* (workflows) — кто и когда отправил, кто одобрил.

## 7. Медиафайлы

- **Изображения** (*Изображения → Добавить*): JPEG/PNG/WebP до 20 МБ. Метаданные (EXIF, в том
  числе GPS) удаляются автоматически. Обязателен **альтернативный текст** («Женщина проходит
  маммографию»), для декоративных картинок отметьте «декоративное».
- **Документы** (*Документы*): PDF и т. п. до 50 МБ. Флажок **приватный** — документ доступен только
  сотрудникам CMS (формы согласия!).
- **Видео** (*Фрагменты → Видео*):
  - *Тип*: длинное / короткое вертикальное (мобилограф);
  - *Источник*: загрузка файла (до 512 МБ) или ссылка YouTube / Telegram / Instagram / TikTok;
  - загруженный файл автоматически перекодируется в 720p и 480p + обложка. Статус:
    *загружено → обработка → готово* (или *ошибка* с текстом ошибки). В статью вставляйте видео со статусом «готово»;
  - субтитры `.vtt` на узбекском и русском, **расшифровка**, врач и организация.

## 8. Истории пациентов

*Страницы → Истории пациентов → Добавить* **Историю пациента**.

- **Имя для показа** — можно псевдоним; отметьте «анонимизировано», если имя изменено.
- **Согласие получено** — без этой отметки страницу **невозможно опубликовать**.
- Для раздела «Детский рак» дополнительно **согласие законного представителя**.
- **Документ согласия** — скан подписанного согласия; автоматически становится приватным и никогда
  не показывается на сайте.
- Диагноз — кратко, словами редактора, без медицинских документов.

## 9. Справочник учреждений («Куда обратиться»)

- Одиночные правки: *Фрагменты → Учреждения*. Поля: название (uz/ru), тип, регион, район, адрес,
  телефон `+998 XX XXX-XX-XX`, часы работы, координаты, «бесплатно по госпрограмме», услуги, раздел, дата проверки.
- **Массовая загрузка** списка от Министерства здравоохранения (делает администратор/разработчик):

  ```
  docker compose exec web python manage.py import_institutions /srv/import/institutions.csv --dry-run
  docker compose exec web python manage.py import_institutions /srv/import/institutions.csv
  ```

  Формат CSV (UTF-8, первая строка — заголовки, пример `data/institutions.sample.csv`):
  `external_id,name_uz,name_ru,kind,region,district_uz,district_ru,address_uz,address_ru,phone,hours_uz,hours_ru,website,lat,lng,free,services,sections,verified_at`

  | Поле | Значения |
  |---|---|
  | `kind` | `svp`, `polyclinic`, `onco_room`, `mother_child_centre`, `oncology_centre`, `paediatric_oncohaematology`, `psych_support`, `ngo` |
  | `region` | `tashkent-city`, `tashkent`, `andijan`, `bukhara`, `fergana`, `jizzakh`, `kashkadarya`, `khorezm`, `namangan`, `navoi`, `samarkand`, `surkhandarya`, `syrdarya`, `karakalpakstan` |
  | `services` | через `;`: `mammography`, `ultrasound`, `hpv_test`, `cytology`, `consultation`, `onco_alertness`, `paediatric_oncology`, `psychological_support` |
  | `sections` | `women`, `children`, `both` |
  | `free` | `1` / `0` |

  Повторная загрузка обновляет записи с тем же `external_id`, дубликатов не создаёт. `--dry-run`
  только проверяет файл и выводит ошибки по строкам.

## 10. Вопросы посетителей (FAQ)

*Фрагменты → Вопросы*. Статусы: **Новый → Отвечен (не публичный) → Опубликован** или **Отклонён**.

- Отвечает врач: поле «Ответ» и поле «Ответил» (выберите себя). Для публикации используйте поле
  «Вопрос для публикации» — отредактированную, обезличенную формулировку вопроса.
- **Опубликовать** можно только вопрос с отметкой посетителя «согласен на публикацию» — иначе статус
  останется «Отвечен».
- Исходный текст вопроса менять нельзя. Если в нём есть имена, телефоны, названия сёл — всё, что
  позволяет узнать человека, — перепишите вопрос без них в «Вопрос для публикации» (пустое поле = на
  сайте показывается исходный текст).
- Контакт посетителя хранится в зашифрованном виде и автоматически удаляется через 90 дней после ответа.

## 11. Глоссарий, материалы, обратная связь

- **Глоссарий** (*Фрагменты → Термины*): термин, определение простыми словами, раздел, синонимы
  (через запятую). Первое упоминание термина в тексте статьи автоматически становится ссылкой-подсказкой.
- **Материалы для распространения** (страница «Материалы»): инфографика, короткие видео, готовые
  подписи uz/ru и хэштеги для блогеров, мужей, родителей, волонтёров.
- **Обратная связь** (*Фрагменты → Обращения*, только Admin): отзывы, сообщения об ошибках,
  предложения партнёрства. Удаляются автоматически через 180 дней.

## 12. Настройки сайта (Admin)

*Настройки → Настройки сайта*: телефоны горячей линии, ссылки на соцсети, текст подвала и
медицинский дисклеймер (uz/ru), **экстренный баннер** (например, месяц скрининга), логотипы
партнёров, ID Яндекс.Метрики, страница политики конфиденциальности, коды подтверждения Яндекс.Вебмастер / Google.

Полезные инструменты (проверка скрининга, самопроверка) включаются разработчиком только после
медицинского согласования текстов (флаги `tools_screening`, `tools_selfcheck`).

## 13. Частые вопросы редакторов

| Проблема | Решение |
|---|---|
| Нет кнопки «Опубликовать» | Так и должно быть у роли Editor — отправьте на модерацию. |
| Изменения не видны на сайте | Страница ещё на проверке или сохранён только черновик; после публикации кэш обновляется сразу. |
| Переключатель языка ведёт на главную раздела | У страницы нет перевода — создайте его (5.2). |
| Не получается выбрать изображение | Обратитесь к администратору: проверьте роль пользователя. |
| Видео в статусе «ошибка» | Посмотрите текст ошибки в карточке видео; обычно повреждённый файл — загрузите заново или используйте ссылку YouTube. |
| Заблокирован вход | 5 неверных паролей → блокировка на 1 час; администратор может разблокировать раньше. |
