# Bemor yo'li (BBS skriningi) — o'zbekcha tarjimani tekshirish uchun

Manba: shifokorning `docs/new_edits/Маршрут_пациентки_РШМ.docx` (2026-11-16), ruscha matn so'zma-so'z saytga qo'yildi (D-113).
O'zbekcha matn — dasturchi tarjimasi, saytdagi atamalarga moslab qilingan. Iltimos, ustunni tekshirib, tuzatishlarni yozing.

| Joy | Ruscha (shifokor) | O'zbekcha (tarjima) |
|---|---|---|
| Sarlavha | Этапы обследования | Tekshiruv qadamlari |
| 1. Bosqich | Приглашение на обследование | Tekshiruvga taklif |
| 1. Matn | Женщин 30–50 лет приглашают на скрининг по списку, не дожидаясь жалоб. | 30–50 yoshdagi ayollar shikoyat paydo boʻlishini kutmasdan, roʻyxat boʻyicha skriningga taklif qilinadi. |
| 1. Qayerda | Семейный врачебный пункт (СВП) / районная поликлиника | Oilaviy shifokorlik punkti (OShP) / tuman poliklinikasi |

| 4.1 Qayerda | Кабинет онконастороженности | «Onkologik hushyorlik» xonasi |
| 4.2 Natija | ВПЧ найден и клетки изменены | HPV aniqlandi va hujayralar oʻzgargan |
| 4.2 Matn | Женщину вызывают на кольпоскопию (осмотр шейки матки). | Ayol kolposkopiyaga (bachadon boʻynini koʻzdan kechirish) chaqiriladi. |
